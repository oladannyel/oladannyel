## How I work

The method is the point, and it is the same on every system above.

- Decisions are recorded as **Architecture Decision Records** — the reasoning survives the
  person who made it.
- Every phase closes against a **gate**: typecheck, lint, build, unit, integration, contract
  and end-to-end tests. A phase that cannot pass its gate is not finished.
- **A public contract is never broken to add a feature.** Contract runs are the release check.
- Where a rule about money, security or permissions is missing, **I stop and ask rather than
  invent one.**
- Honest reporting over flattering reporting: coverage, limits and the things that do not work
  get written down.
